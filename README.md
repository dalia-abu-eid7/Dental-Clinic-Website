Multi-Page Medical Center Website (Front-End)
Overview
A complete, responsive, multi-page web solution designed for modern medical centers and clinics. This project prioritizes a seamless User Experience (UX) and a clean, trust-building User Interface (UI), ensuring patients can easily access information and book appointments on any device.

Key Pages
The website is structured into distinct, logically organized pages:

Home Page: Featuring an interactive hero section, a strategic overview of clinic services, a counter for key clinic statistics, and a patient testimonials carousel to build credibility.

About Us: Detailing the clinic's mission, vision, and core values, along with a gallery showcasing facilities.

Services Page: A categorized catalog of medical specializations, presented in clean, visually distinct cards for clarity.

Our Doctors: Profiles of the medical team, including professional photos, specializations, and experience.

Appointments Page: A sophisticated booking form allowing users to select departments, doctors, and desired time slots.

Health Blog: A platform for medical articles and health tips, designed for optimized readability.

Contact Us: Including dynamic Google Maps integration, contact details, and open hours.

Technical Stack & Features
HTML5 & CSS3: For advanced structuring and professional styling.

Bootstrap 5: Ensures the website is fully responsive across mobiles, tablets, and desktops using the powerful grid system.

JavaScript (ES6+): For enhanced interactivity, including the testimonials carousel, dynamic form validation, and interactive UI elements.

Performance Optimization: Efficient use of assets and clean coding practices to achieve fast page load times.

Cross-Browser Compatibility: Thoroughly tested to function flawlessly on Chrome, Firefox, Edge, and Safari.
